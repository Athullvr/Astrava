# 🚨 WhatsApp Forward FIR Report Generator 📜

A satirical cyber-police FIR (First Information Report) generator designed for **TinkerHub Useless Projects 3.0**. Paste unverified WhatsApp forwards, 4 AM hot-lemon-5G radiation cures, and 6 AM glittering good morning flower spam, and receive an authentic, vintage-styled police FIR complete with fake IPC sections, deadpan Investigating Officer (IO) remarks in Manglish, official red rubber stamps, and ridiculous penalties.

### Project Description
An AI-powered satirical cyber-police document generator operated by the fictional *Kerala Digital Satya Pramanam Vibhagam (KDSPV)*. It transforms ridiculous family group forwards into high-stakes, official-looking FIR documents with vintage typewriter styling, distressed rubber stamps, and absurd disciplinary sanctions.

### The Problem (that doesn't exist)
Uncensored uncle propaganda, UNESCO anthem awards, 4:32 AM lemon-water antiviral theories, and 500GB free Ambani recharge phishing links are circulating freely in family WhatsApp groups without proper legal prosecution, causing emotional trauma and storage-full notifications across Kerala.

### The Solution (that nobody asked for)
An official-looking statutory digital police station that generates instant First Information Reports (F.I.R. Form No. 420-M) charging forwarders under *Sec 420-B (Vishwasa Chooshanam)*, *Sec 69-U (Uncle Forward Pledge Act)*, and *Sec 302-G (Murder of Common Sense)*, with court orders revoking WhatsApp Admin privileges and Wi-Fi access.

## Implementation

### Installation
```bash
# Clone the repository
git clone https://github.com/Athullvr/astrava.git
cd astrava

# Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Run
```bash
# Option 1: Launch Gradio Web App (Port 7860)
python3 app.py

# Option 2: Open standalone interactive HTML version in browser
xdg-open index.html # Or open in Chrome/Firefox
```
